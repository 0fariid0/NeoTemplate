# دو نسخه مستقل Neo Smart

## 1) نسخه بدون نمودار

- نام: `Neo Smart`
- شناسه: `neo-smart`
- نسخه: `1.1.1`
- بدون نیاز به تغییر backend پنل

```bash
neotemplate install neo-smart
```

## 2) نسخه دارای نمودار

- نام: `Neo Smart Usage`
- شناسه: `neo-smart-usage`
- نسخه: `1.0.0`
- دارای انتخاب بازه ۲۴ ساعت و ۳۰ روز
- بازه پیش‌فرض: ۳۰ روز
- نیازمند پچ backend تاریخچه مصرف

```bash
neotemplate install neo-smart-usage
```

هر دو نسخه ظاهر و قابلیت‌های اصلی Neo Smart را دارند. تفاوت فقط در بخش نمودار تاریخچه مصرف و نیاز نسخه دوم به پچ پنل است.
